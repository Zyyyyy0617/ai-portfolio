# 学生习作（HSK4 学生作文，含典型小错误）

题目：坚持很重要
虽然学习中文很难，但是我不害怕。我每天读课文，写汉字。有时候我学很累，我想休息。愚公九十岁，他坚持移山。他的故事被我感动。总有一天，我学好中文。坚持可以帮助我实现目标。

## 作文批改

1. **字词**：无错字，用词基本合适。本课生词：坚持 (HSK4)
2. **标点**：全部标点为中文标点，无明显错误。
3. **语法**
① 有时候我学很累 → 错误：语序不当。“累” 是形容词，不能放在宾语后面。
② 他的故事被我感动 → 错误：被字句施事、受事颠倒。应该是 “我被故事感动”。
③ 总有一天，我学好中文 → 错误：缺少能愿动词，“总有一天” 后面常搭配 “会”，表示将来。
4. **优化**
【原文】有时候我学很累
【修改句】有时候我学得很累

【原文】他的故事被我感动
【修改句】我被他的故事感动

【原文】总有一天，我学好中文
【修改句】总有一天，我会学好中文

5. **微调后全文**
虽然学习中文很难，但是我不害怕。我每天读课文，写汉字。有时候我学得很累，我想休息。愚公九十岁，他坚持移山。我被他的故事感动。总有一天，我会学好中文。坚持可以帮助我实现目标。
6. **评语加分数**
评语：文章紧扣主题，正确使用本课重点语法 “虽然…… 但是……”、生词 “坚持”，还尝试使用被字句、总有一天。中心意思清楚。有几处典型语序、被字句的小错误，修改之后句子会更地道。可以增加一点细节，写一写你怎么坚持学习中文。
得分：13/20
