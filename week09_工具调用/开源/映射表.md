# 五步映射表（W9 手写循环 → smolagents A 层）

对应代码：`a_layer_smolagents.py`。全班最低要求：本表放进 `week09/`。

| # | W9 手写环节 | smolagents 对应 | 本代码中的证据 | 我验证了什么 |
|---|---|---|---|---|
| 1 | `TOOLS = {"get_time": ..., "calc": ..., "hsk_level": ...}` | `@tool` 把函数变成 Tool，交给 `ToolCallingAgent(tools=[...])` | `TOOL_FUNCS = [get_time, calc, hsk_level, hsk_words_by_level]`，`build_agent()` 传入 | `show_tool_schema()` 打印出每个工具的 `name / inputs / description` |
| 2 | `SYS` 要求模型输出一行 JSON | 模型原生 tool calling（JSON-like），框架自动把工具说明写进系统提示 | 代码里不再有 `SYS` 和手写 JSON 格式说明；`instructions=` 只补角色，不写调用格式 | 运行截图中模型直接产生工具调用，而不是输出 `{'tool': ..., 'args': [...]}` 文本 |
| 3 | `parse_calls()` 剥围栏、单引号转双引号、正则兜底 | 框架内部解析 `ChatMessageToolCall` | 已删除 `json / re` 解析逻辑和 `parse_calls()` 函数 | 模型即使输出 JSON-like 内容，框架也能识别工具调用；运行截图可见 calling tool 记录 |
| 4 | `TOOLS[call["tool"]](*args)` | 按 `Tool.inputs` 校验参数后调用，结果写回多步消息 | `@tool` 函数的类型注解 + `Args:` docstring 生成 `inputs`；`get_time / calc / hsk_level / hsk_words_by_level` 保持原逻辑 | `--selftest` 中 `calc('35*24')` 正常、注入表达式被拒绝；`hsk_level('把')` 返回等级 |
| 5 | `for _ in range(max_calls)` 手动喂回 + 最后补一次调用 | `MultiStepAgent` 管理多步循环与停止条件 | `ToolCallingAgent(..., max_steps=2)` 对应 W9 的 `max_calls=2` | 运行后打印 `agent.logs`，可数出实际步数不超过 2 |

## 安全与来源

- `calc()` 继续使用 AST 白名单，只允许数字和 `+ - * / ** %`，**没有使用裸 `eval`**。
- `.env` 与 `DEEPSEEK_API_KEY` 不入库；截图前确认画面里没有密钥。
