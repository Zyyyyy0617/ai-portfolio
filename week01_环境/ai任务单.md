# 教学任务单
## 任务1
**任务指令**：为《愚公移山》生成五道阅读理解题，附答案和解析
**任务输出**：
阅读文本（节选）
太行、王屋二山，方七百里，高万仞，本在冀州之南，河阳之北。

北山愚公者，年且九十，面山而居。惩山北之塞，出入之迂也，聚室而谋曰：“吾与汝毕力平险，指通豫南，达于汉阴，可乎？”杂然相许。其妻献疑曰：“以君之力，曾不能损魁父之丘，如太行、王屋何？且焉置土石？”杂曰：“投诸渤海之尾，隐土之北。”遂率子孙荷担者三夫，叩石垦壤，箕畚运于渤海之尾。邻人京城氏之孀妻有遗男，始龀，跳往助之。寒暑易节，始一反焉。

河曲智叟笑而止之曰：“甚矣，汝之不惠！以残年余力，曾不能毁山之一毛，其如土石何？”北山愚公长息曰：“汝心之固，固不可彻，曾不若孀妻弱子。虽我之死，有子存焉。子又生孙，孙又生子；子又有子，子又有孙；子子孙孙无穷匮也，而山不加增，何苦而不平？”河曲智叟亡以应。

操蛇之神闻之，惧其不已也，告之于帝。帝感其诚，命夸娥氏二子负二山，一厝朔东，一厝雍南。自此，冀之南，汉之阴，无陇断焉。

1. 词语解释：对下列句中加点词解释有误的一项是（）
A. 年且九十（将近） B. 寒暑易节（容易） C. 始一反焉（同“返”，往返） D. 汝之不惠（同“慧”，聪明）
答案：B
解析：“易”是更替、交换，句意：冬夏换季，才往返一次。

2. 虚词理解：下列加点“之”字用法与其他三项不同的一项是（）
A. 惩山北之塞 B. 曾不能毁山之一毛 C. 虽我之死，有子存焉 D. 冀之南，汉之阴
答案：C
解析：A、B、D的“之”为结构助词“的”；C用于主谓之间，取消句子独立性，不译。

3. 句子翻译：子子孙孙无穷匮也，而山不加增，何苦而不平？
答案：子子孙孙无穷无尽，可是山不会再增高加大，还怕挖不平吗？
解析：重点字词：穷匮（穷尽）；加增（增高加大）；何苦（担心什么），保留反问语气。

4. 内容理解：文中愚公妻子和智叟都对移山提出质疑，两人的态度有什么不同？
答案：愚公妻子是出于关心提出疑问，不反对移山，担忧土石无处安放；智叟是讥笑、阻止愚公移山，持反对态度，嘲讽愚公不自量力。
解析：妻子“献疑”是善意商量；智叟“笑而止之”带有轻蔑，否定移山这件事。

5. 主旨感悟：这篇寓言故事告诉我们什么道理？请简要概括。
答案：只要有坚定信念，坚持不懈，不怕困难、持之以恒，就有可能战胜困难。
解析：故事核心是人的恒心与决心，不能简单理解为依靠神仙解决问题。

## 任务2
**任务指令**：把《愚公移山》教案要点扩展成完整教案片段（含导入、操练，活动，作业），精简为一段文字
**任务输出**：
导入以“遇到大山挡路你会怎么做”引发思考，带领学生朗读课文疏通文意，开展字词抢答操练；组织小组活动对比愚公妻子与智叟的质疑差异，探讨愚公形象；最后布置分层作业，巩固文言知识并写写对愚公精神的理解。

## 任务3
**任务指令**：为语法点“把”字句设计10分钟课堂互动活动
**任务输出**：
语法点：把字句（主语+把+宾语+动作+结果），适用对外汉语/小学语文，总时长10分钟
1. 导入（2分钟）：教师实物动作演示，“我打开书”→“我把书打开”，点明句式：谁 + 把 + 什么 + 怎么样了，把字句用来强调动作带来的结果、状态变化。
2. 基础操练（3分钟）：师生接龙改写句子，例：我关上窗户→我把窗户关上；我写完作业→我把作业写完，学生说出完整把字句，纠正语序错误。
3. 情景互动活动（4分钟）：游戏《我来做，你来说》，学生上台做擦黑板、倒水、翻书等动作，全班举手用把字句描述动作结果，要求句子成分完整，语序正确。
4. 小结+微作业（1分钟）：小结：把字句用来表述事物经过动作改变状态或位置；微作业：观察身边3个动作，各写一句把字句。

## 反思
教学设计不能只追求活动热闹，更要紧扣知识点目标，控制好课堂时间，保证学生扎实掌握核心内容。
